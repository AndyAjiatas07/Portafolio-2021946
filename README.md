## ✨ Características

- 🏠 **Inicio** — presentación de mis roles y mis dominios generales
- 🧑‍💻 **Sobre mí** — perfil, datos generales, habilidades por categoría con barras visuales, educación y experiencia
- 📁 **Proyectos** — grid de proyectos con detalle en página propia
- 📫 **Contacto** — enlaces directos a LinkedIn, Email y GitHub
- 🎨 Diseño responsive, con paleta propia por capa de stack (frontend / backend / base de datos / herramientas)

## 📦 Instalación

```bash
git clone https://github.com/AndyAjiatas07/portafolio-2021496.git
cd portafolio-2021496
npm install
npm run dev
```

Otros comandos:

```bash
npm run build     # build de producción
npm run preview   # previsualizar el build
```

## 🧭 Rutas

| Ruta             | Página                                                        |
| ---------------- | ------------------------------------------------------------- |
| `/`              | Bienvenida                                                    |
| `/sobre-mi`      | Perfil, datos generales, habilidades, educación y experiencia |
| `/proyectos`     | Grid de proyectos                                             |
| `/proyectos/:id` | Detalle de un proyecto                                        |
| `/contacto`      | LinkedIn, Email, GitHub                                       |

## 🗂️ Estructura del proyecto

```
src/
 ┣ app/            → App.jsx, main.jsx, layout raíz y definición de rutas
 ┣ features/        → una carpeta por sección (home, about, projects, contact)
 ┣ shared/          → componentes, utilidades reutilizables (Navbar, Footer, Badge...)
 ┗ styles/          → tokens de diseño globales (colores, tipografías)
```
